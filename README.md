# Controle de Corridas

Projeto desenvolvido em Python para realizar o cadastro e controle de corridas.

O sistema permite registrar corridas realizadas por motoristas de aplicativos, visualizar as corridas cadastradas e calcular o valor total ganho.

##  Tecnologias utilizadas

- Python

##  Funcionalidades

- Cadastro de corridas
- Registro do valor da corrida
- Registro da distância percorrida
- Visualização das corridas cadastradas
- Cálculo do valor total ganho
- Menu interativo
- Validação de opções do menu

##  Como executar o projeto

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Certifique-se de ter o Python instalado.
4. Execute o arquivo principal com o comando:

```bash
python main.py
